# Akanara — Logo files

The Akanara mark is a gold "A" peak — a mountain/ascent for Bali and forward motion,
in the brand's Balinese-gold gradient. All files are vector SVG (scale to any size,
never blurry).

- Ink `#211A15` · Paper `#FBF6EF`

## Rules of thumb
- **Clear space:** keep at least the height of the "A" mark clear on all sides.
- **Minimum size:** mark no smaller than 24px; full lockup no smaller than ~120px wide.
- **Don't:** stretch, recolour outside the palette, add shadows/outlines, rotate, or
  put the gradient mark on a busy photo (use the reversed or one-colour version there).

## About the wordmark font
The lockups set "Akanara" in **Clash Display** (the site's display font) with a system
fallback. When you open a lockup SVG on a computer **without** Clash Display installed,
the wordmark falls back to a system sans. The **mark/icon files are pure vector** and
look identical everywhere.

To make a lockup 100% portable (for print, other designers, etc.), open it in Figma or
Illustrator with Clash Display installed and **outline/convert the text to paths**, then
re-export. Clash Display is free from fontshare.com. (Happy to do this for you if you
share the font file.)
